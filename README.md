# 英语语法全景 · 学习系统

一套把英语语法拆到「可独立出题的最小规则」之后，再用记忆曲线逼你真正记住的本地系统。

**7 个一级分类 · 57 个章节 · 278 个三级知识点 · 1650 道固定训练题 · 3450 道变式（278 点全覆盖）**

每个知识点都走同一条闭环：

```
学习（完整讲解） → 学习训练 → 复习（主动回忆 + 自评） → 复习训练 → 按记忆曲线排下一次
```

## 一、启动

双击 `start.bat`，或命令行：

```bash
python run.py            # 自动打开 http://127.0.0.1:8765
python run.py --no-browser
python run.py --host 0.0.0.0   # 局域网模式，手机可访问（也可双击 start-lan.bat）
```

首次运行需要装依赖：

```bash
python -m pip install -r requirements.txt
cd web && npm install && npm run build && cd ..
```

前端改完后重新 `npm run build` 即可；开发模式用 `npm run dev`（5173 端口，已配好 `/api` 代理）。构建产物输出到 `web/site`（不用 `dist`，避免云端上传时被当成构建目录剔除）。

## 三、记忆曲线怎么算

调度器实现 **FSRS-4.5**，不是简单的「1 天 / 3 天 / 7 天」阶梯。

每个知识点维护三个量：

| 量                  | 含义                                    |
| ------------------ | ------------------------------------- |
| stability `S`      | 记忆稳定度，约等于「回忆概率降到 90% 所需天数」            |
| difficulty `D`     | 该点的固有难度，1~10                          |
| retrievability `R` | 当前可回忆概率，`R = (1 + FACTOR·t/S)^(-0.5)` |

- **答对**：`S` 按 `exp(w8)·(11-D)·S^(-w9)·(e^((1-R)·w10)-1)` 增长，答得越轻松（easy）增幅越大
- **答错**：`S` 按遗忘公式重算，降到接近 0，10 分钟后重新出现
- **难度**：`D` 随评分调整并向均值回归，避免发散
- **间隔**：`I = (S/FACTOR)·(r^(1/-0.5) - 1)`，目标留存率 `r` 可在设置里调 85% / 90% / 95%
- **顽固点**：累计遗忘 4 次标记 leech，下次复习强制插入完整讲解再做题

评分不靠自评单点：**复习 = min(自评, 正确率折算)**，学习阶段首次接触最高只给 3 分（good），防止一次做对就跳到两周后。

掌握度（0~100）四项加权：

```
30% 记忆稳定度（S 到 45 天满档）
30% 近期正确率
15% 题目覆盖（做过 4 道以上不同题满档）
25% 当前可回忆概率
```

这样「曾经学过但已经忘了」不会显示成高掌握。

## 四、一次会话里发生什么

| 模式 | 队列                   | 评分方式            |
| -- | -------------------- | --------------- |
| 学习 | 讲解 → 4 道题            | 按本组正确率折算，上限 3 分 |
| 复习 | 回忆卡（自评） → 3 道题       | 自评与正确率取更保守一方    |
| 训练 | 4 道题，不改动排期           | 只记题目统计与错题       |
| 生长 | 按拓扑前沿取 4 点：讲解 → 4 道题 | 同「学习」           |
| 回看 | 只发讲解，**不发题**         | 不打分，也不改排期       |
| 考试 | 按考试类型加权抽题，限时         | 整卷判分，错题入错题本     |

选题不是随机抽：权重 = 没做过(+4) + 错误率×4 + 距上次天数 + 上次答错(+1.5) + 难度轻微惩罚，并强制前两题题型不同，避免同一题型的机械重复。

复习队列排序：顽固点优先 → 可回忆概率越低越靠前。

**回看（只复习概念）** 是唯一的「只读」模式：把完整讲解（判定标准、例句含错例、易错对比、记忆锚点）按记忆曲线排给你——顽固点优先，其次最快会忘的，同一紧迫度下优先挑最近没回看过的。翻完点「看完了」，记一次阅读记录。

它刻意**不碰 FSRS 的稳定度与难度**：如果读一遍讲解就算一次复习，间隔会被推远、题却一道没做，记忆曲线立刻失真。所以它解决的是「考前想扫一遍规则」「错题后想回看那条讲解」，不承担复习职能。入口在今日页的「只看讲解」和「我的 → 概念回看」，每轮几个在设置里调（默认 8）。

## 五、成长拓扑

`prereq` 里的依赖关系不是摆设，它被算成一张可走的地图。

**图的算法**

- 点级：312 条依赖边组成 DAG（已校验无环），层级 = 最长前置链，共 9 层。同一层彼此无依赖，可以任意顺序学。
- 章级：知识点之间互有引用，章与章之间会出现环（例如「名词」里有点依赖「冠词」，「冠词」里又有点依赖「名词」）。因此章级用**强连通分量缩点**处理：环里的章节合并成同一层，而不是硬砍一条边。当前有 1 组这样的环（名词 ↔ 冠词）。
- 回边（指向同层或更浅层）用虚线画，不参与分层。

**四种状态**

| 状态  | 判定           |
| --- | ------------ |
| 未解锁 | 至少一个前置从未学过   |
| 可学  | 前置全部学过，自己没学过 |
| 学习中 | 学过但掌握度未到     |
| 已掌握 | 掌握度达标        |

关键取舍：**只按「前置是否从未学过」上锁，不因为前置遗忘而重新上锁**。否则你复习不到位一次，后面 30 个点全部变灰，人直接被劝退。

还有一条：**拓扑和自选不冲突，是两条并列入口**。拓扑负责「不知道学什么时按价值推荐」，课程页自选负责「我心里有数直接挑」。默认 `prereq_gate=0`，图上的「未解锁」只是状态标注，不拦任何操作——课程页不会变灰，拓扑详情里的「学这个」也照常能开。只有手动打开严格前置锁定后，学习模式才会跳过被锁的点并告诉你缺哪几个。

**「下一站」怎么排序**

按解锁价值 = 该点传递闭包上的后置节点数。同样的「现在能学」，先学能开出更多路的那一个。所以系统会先推「动词的四种基本形式」（解锁 54 点），而不是按章节顺序推「名词」。

**到达路径**

点任何一个点，都能看到从零到它的完整前置链（按拓扑深度排好序，天然可执行），以及还差几步、大约多少分钟。可以直接按顺序学掉前 4 个前置。

**严格模式**

设置里可开启「严格前置锁定」：学习模式会跳过前置未完成的点，并告诉你缺哪几个；复习永远不受限制（能复习说明已经学过）。

## 六、判分规则

- 归一化只处理与语法无关的差异：大小写、全角半角、弯引号、多余空格、句末标点
- 选择题：必须与选项逐字相同
- 填空 / 改错：命中 `accept` 任一写法即对
- 重组：去空格后与标准句完全一致
- 翻译：`require` 是二维数组，**每一组必备结构都要命中**；命中任一 `forbid` 结构即判错。部分命中会显示「命中 x%」并列出缺哪一块

翻译题不给「差不多就行」的模糊分——这是刻意的，宁可判严，也不让中式表达混过去。

## 七、变式题：固定题库管判分，模板变式管抗遗忘

1650 道固定题是主干：答案写死在内容里，判分走 `grade.py` 的精确匹配，永远不会自相矛盾。但固定题做两遍就会变成「背题号」——错题本一翻就知道选 B。

所以加了一层**确定性变式**（`server/variants.py`）：

- 每个受支持的知识点写好「槽位 + 词表」的模板，题干由模板拼出来，**答案由模板算出来**（`_conj(verb, tense, sing)` 这类函数负责动词变形），不是让模型现编
- 判分完全复用 `grade.py`，和固定题一条流水线，因此不存在「生成器认为对、判分器认为错」
- 同一知识点用 `seed` 采样 24 次，同题干去重，得到 24 个互不相同的变体

**覆盖**：278 / 278 个知识点全部有变式，产出 **3450 道**、去重后 **3299 个不同题干**，结构自检 0 问题（选项恰好 4 项且答案逐字在内、填空含 `___`、`accept` 含标准答案、id 唯一）。每个知识点都能出 12 道互不相同的题，足够撑过二刷三刷。

| 一级   | 覆盖          |
| ---- | ----------- |
| 词法   | **79 / 79** |
| 时态语态 | **42 / 42** |
| 句法   | **35 / 35** |
| 非谓语  | **27 / 27** |
| 从句   | **29 / 29** |
| 特殊句式 | **41 / 41** |
| 搭配   | **25 / 25** |

### 两条生成路线

**一、模板推导（`server/variants.py`）**——题面由槽位拼出来，答案由函数算出来。适用于空位被结构唯一决定的知识点：

- 非谓语：介词后必 doing、make / let 后必原形、the first 后必定式、too ... to 后必不定式
- 从句：先看有没有先行词，再看从句缺不缺成分，最后看缺的是主 / 宾 / 表 / 状语
- 冠词、主谓一致、时态形式、被动语态、倒装、反意疑问、虚拟语气、比较结构、so/such 等

**二、数据池（`server/vp_*.py`）**——每个知识点写 12 条「题干 / 答案 / 三个干扰项 / 解析」，由 `_g_pool_choice` 包成生成器。适用于答案挂在词项本身、无法参数化的部分：

| 文件              | 内容                                      |
| --------------- | --------------------------------------- |
| `vp_morph.py`   | 名词、代词、数词 19 点                           |
| `vp_morph2.py`  | 形容词副词、介词 16 点                           |
| `vp_morph3.py`  | 连词、动词、构词法 21 点                          |
| `vp_syntax.py`  | 句子成分、五种句型、并列句、there be、it、句类、否定、语序 23 点 |
| `vp_tense.py`   | 24 个时态语态的对比点                            |
| `vp_special.py` | 强调、省略、替代、反意疑问、虚拟、比较、平行、祈使 27 点          |
| `vp_colloc.py`  | 短语动词、介词搭配、固定句型、易混词、填空策略 25 点            |

搭配这一块最后也做了：答案确实挂在词项上，但可以反过来做——**一条高频词项配三个最容易被混用的干扰项**（`turn off / turn down / turn out`、`angry with sb / angry at sth`、`economic / economical`），靠选项把语义边界逼出来。这样既不用参数化，也不会退化成背单词表。

### 写池子的三条硬规则

1. **干扰项必须「错得干净」**。只收明确违反语法或语义的选项，绝不拿「语法成立但不够自然」的来凑数——判断题一旦靠语感偏好，就会冤枉人。
2. **题干逐条不同**。`make()` 会按题干去重，同一个池里出现两条一样的问句，整池会被压成一道。
3. **两种说法都成立的空位不做填空**。`prefer to do / doing`、`each of us ... our / his` 这类一律改成形式唯一的考点，或者整题换掉。

**四档开关**（我的 → 变式题）：

| 档位         | 行为                         |
| ---------- | -------------------------- |
| 只用固定题      | 完全不掺变式（默认关闭时用这个）           |
| 每点 1 道（默认） | 一组 4 题里放 1 道变式，用于即时检验是不是真会 |
| 各占一半       | 固定题与变式题对半                  |
| 全部变式       | 整组都是变式（适合二刷、三刷）            |

变式题**不写回 `content/`**，只活在会话状态里；一旦答错，才落进 `gen_drill` 表，这样错题本能把题干、选项、解析、答案原样还原出来（错题本会标「变式」）。

```bash
python tools/test_variants.py     # 变式题库结构自检，并打印每个知识点的产量
```

## 八、App 形态与双端适配

同一套代码，两套外壳：

| 断点      | 外壳                                                                           |
| ------- | ---------------------------------------------------------------------------- |
| > 900px | 左侧固定侧栏（7 项导航 + 连续打卡卡片），右侧内容区，弹层居中                                            |
| ≤ 900px | 顶部栏（标题 / 学习页返回箭头 / 待复习数 / 打卡天数）+ 底部 5 标签栏（今日 · 课程 · 拓扑 · 报告 · 我的），弹层从底部弹起成抽屉 |

手机端细节：会话页进入沉浸模式（隐藏标签栏，只留顶部返回），选项按钮 44px 以上触控高度，提交栏吸底，卡片单列堆叠，课程分类改成横滑胶囊，安全区 `safe-area-inset` 与 `100dvh` 都做了处理，横屏另有一套紧凑规则。

**iPhone 添加到主屏幕**

1. 电脑和手机连同一个 Wi-Fi，双击 `start-lan.bat`（等价于 `python run.py --host 0.0.0.0`）
2. 启动日志会打印两行地址，手机用 Safari 打开「手机」那一行，形如 `http://192.168.0.161:8765`
3. 分享 → 添加到主屏幕 → 名称「语法全景」

如果手机打不开，多半是 Windows 防火墙拦了：第一次启动时弹窗要选「允许访问」，或到防火墙入站规则里放行 Python。

装到主屏后是全屏无地址栏的独立窗口：`manifest.webmanifest` 提供图标与 `standalone` 模式，`sw.js` 缓存静态资源（导航请求网络优先、`/api` 永不缓存，避免进度读到旧值）。注意 Service Worker 只在 `localhost` 或 HTTPS 下生效，所以用 IP 访问时离线缓存不会启用，联网即可正常用。

**跨设备进度**：局域网模式下，手机和电脑连的是同一个服务，读写的也是同一份 `data/grammar.db`，所以**进度天然同步**，不需要导入导出。云端实例是另一份独立的库，本地与云端之间要用设置页的导出 / 导入搬数据。

## 十、扩充内容

1. 在 `content/_taxonomy.json` 的对应章节 `points` 数组里加标题
2. 新建/修改 `content/{一级}/{章节}.json`，按 `docs/content-spec.md` 填写
3. 校验：

```bash
python tools/validate_content.py                    # 全量
python tools/validate_content.py content/clause/relative_clause.json
```

校验器会查：JSON 合法性、标题与 taxonomy 逐字对齐、id 唯一、选项与答案一致、填空含 `___`、题型覆盖、反面例句数量、答案可归一化、题干重复等。**0 error 才能进库**——`content.py` 在启动时还会再校验一次，不一致直接拒绝启动。

## 十一、数据安全

- 所有进度在 `data/grammar.db`（SQLite，WAL 模式）
- 设置页可导出完整 JSON 备份，换机导入即恢复
- 内容与进度分离：改内容不会动学习记录，id 不变则记录继续有效
